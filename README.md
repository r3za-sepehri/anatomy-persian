# Anatomy Atelier — آناتومی را مانند یک هنرمند بیاموزید

پروژه Anatomy Atelier یک برنامه تحت وب تعاملی است که به کاربران اجازه می‌دهد آناتومی بدن انسان (مانند قلب، مغز، ریه‌ها، کبد، کلیه‌ها، چشم، روده، پانکراس و پوست) را از طریق مدل‌های سه‌بعدی و جذاب یاد بگیرند و کاوش کنند.

## پشتیبانی از زبان فارسی 🇮🇷

**پشتیبانی از زبان فارسی به این پروژه اضافه شده است!**
من این قابلیت و ترجمه‌های فارسی را با کمک دستیار هوش مصنوعی **Antigravity** به پروژه اضافه کردم تا کاربران فارسی‌زبان نیز بتوانند از این محیط آموزشی بهره‌مند شوند.

## ویژگی‌ها

- نمایش سه‌بعدی و تعاملی اعضای مختلف بدن انسان.
- قابلیت چرخش، بزرگ‌نمایی، برش عرضی و جداسازی لایه‌های مختلف.
- رابط کاربری زیبا با پشتیبانی کامل از چینش راست‌به‌چپ (RTL) برای زبان فارسی.
- حاوی اطلاعات دقیق پزشکی، توضیحات کاربردی و حقایق جالب درباره هر عضو.

## نحوه اجرای پروژه (Quick Start)

برای اجرای این پروژه روی سیستم خود، به نسخه `Node.js >= 22` نیاز دارید. مراحل زیر را در محیط خط فرمان (ترمینال) خود اجرا کنید:

```bash
# نصب پیش‌نیازها (Dependencies)
npm install

# اجرای سرور توسعه محلی (Development Server)
npm run dev
```

پس از اجرای دستورات بالا، در مرورگر خود به آدرس `http://localhost:3000` مراجعه کرده و از منوی زبان در بالای صفحه، **"فارسی"** را انتخاب کنید تا محیط برنامه کاملاً به زبان فارسی تغییر یابد.
